# Harbor brand

Harbor is a container registry with a web console. This page is the brand reference for anyone building the console.

## Colour

- **Harbor Violet** `#7C3AED`: the accent. Primary buttons, links, the focus ring, selected tabs.
- **Deep Water** `#111827`: text on light grounds, and the dark-mode background.
- **Foam** `#F9FAFB`: the light-mode background.
- **Kelp** `#059669`: success states (image pushed, scan clean).
- **Coral** `#DC2626`: errors and destructive actions.

## Type

System UI stack for everything; `ui-monospace` for digests, tags and sizes.

## Shape

6px corners on buttons and inputs, 10px on cards.
