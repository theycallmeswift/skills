# Link

Inline text links and "View all" links.

| State | Colour | Decoration |
|---|---|---|
| default | `--accent` | none |
| hover | `--accent` | underline |
| focus-visible | `--accent` | 2px `--accent` outline, 2px offset |

Do: use `<a>` for navigation. Don't: colour non-link text with `--accent`.
