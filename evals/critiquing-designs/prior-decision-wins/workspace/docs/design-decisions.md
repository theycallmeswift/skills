# Pulse design decisions

Newest first. Each entry is settled until its owner reopens it.

## 2026-11-12: Test matrix cells are colour-only
Removed the text badges from the matrix cells. Colour plus the hover tooltip carries status; at 31
columns the badges turned the matrix into noise. Owner: Swift.

## 2026-11-12: Test matrix summary stays "27/31 passed"
The pass count is the number the team tracks in standup, so the header keeps "27/31 passed".
Owner: Swift.

## 2026-10-02: Icon-only nav
The left nav stays collapsed to icons by default and expands on hover; power users wanted the
width. Owner: Priya.

## 2026-09-14: Inter everywhere
Inter for all UI text, system-ui fallback. Owner: Priya.
