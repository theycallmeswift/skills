# Pulse design tokens (light theme)

| Token | Value | Use |
|---|---|---|
| `--page` | #FFFFFF | Page background |
| `--nav` | #F0F2F6 | Icon nav background |
| `--icon` | #C9CED8 | Nav icons |
| `--band` | #F7F8FB | Note band under the header |
| `--text` | #111827 | Headings, suite labels, run summary |
| `--text-muted` | #8B93A1 | Subtitle, "Last run" column and timestamps |
| `--text-note` | #5E677B | Note text on the band |
| `--pass` | #12B76A | Passing matrix cell |
| `--fail` | #D92D20 | Failing matrix cell |
| `--danger` | #B42318 | Error text |

Type: Inter; 12, 13, 18, 22px. Matrix cells 16x20px with 4px gaps. Spacing on a 4px grid.
